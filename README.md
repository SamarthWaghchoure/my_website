# BrightPath International School — Website Portfolio Demo

This is a fictional school website concept created as a portfolio project.

## Files
- `index.html` — page structure and content
- `styles.css` — responsive styling
- `script.js` — mobile navigation and demo enquiry-form interaction

## How to view
Open `index.html` in a modern browser. An internet connection is needed for the external Google Fonts and Unsplash images.

## Before using in a job application
- Clearly label this as a personal concept/prototype, not client work.
- Replace or customise the name, copy, statistics, dates and images if you continue developing it.
- The statistics and events are illustrative placeholders.
- The enquiry form is front-end only; it does not send or store data.
- Do not imply that the website was built for a real school or employer.
- If publishing online, use assets you have permission to use and review their licenses.
